# Speech-Emotion-Analyzer
The Speech Emotion Analyzer is a simple web application that uses Natural Language Processing (NLP) to detect emotions (Happy, Neutral, or Sad) from user input. Built with Python Flask on the backend and HTML, CSS, and JavaScript on the frontend, it allows users to speak or type text, which is then analyzed using NLTK's SentimentIntensityAnalyzer. The app features a clean user interface, real-time speech recognition, and displays the detected emotion based on sentiment scores. It’s an ideal mini-project demonstrating the integration of speech input, sentiment analysis, and web technologies.
